# 教学质量、产物验收与试跑

## 框架评审

候选方案分别说明降低的理解障碍、关键认知转折、依赖是否顺畅、迁移能力及代价。检查故事或悬念是否增加无关认知负担；直接清晰的结构同样可选。比较具体路径和样例，不按形式新奇程度评分。

## 证据质量

论断区分通用原理、特定实现事实、实验观察、厂商主张及教学假设。实现事实绑定版本或提交；效果主张保留测试条件、指标及局限，尽可能用独立证据核验。官方文档可证明接口行为，不能独自证明普遍优越性。缺乏充分证据时限定说法、标注未知或移除。构造案例、模拟输出与真实运行结果分别标明。

## 试讲执行协议

每次写明课程及版本、讲述人、评审人、学员背景、覆盖段落、方式和目标。按以下证据类型分别记录：

1. Agent 讲稿预演：检查逻辑、术语和话术，标记模拟，不能证明真实可理解性。
2. 课程负责人试讲评审：用户实际讲述或审阅讲稿，记录停顿、转场、难点和用时。
3. 目标学员试读或试讲：记录实际前置能力、关键问题回答、卡点、完成时间与反馈。无参与者时标记未开展，不默认课程失败，也不宣称真实教学效果已验证。

问题记录具体页面或单元、观察到的现象、对应原话或回答、影响、严重性、修改建议及复核方式。区分材料缺陷、讲述表现与学员基础不足；不把所有错误归咎于学员。使用预测、因果解释、反例判断或约束变化问题检查理解。用少量代表性问题获得信息，避免把短课变成长考。

## 视觉与附件验收

样页明确字体、配色、图形语法、布局和可编辑源文件位置，技术语义与视觉参数分开维护。晚期改风格先列受影响文件、重制成本、时间与已评审版本变化，评估后按授权范围执行。

| 产物 | 最低验收证据 |
|---|---|
| PPT 与讲稿 | 打开或渲染实际文件检查溢出、字体、图示、术语和备注；核对目标覆盖及页序 |
| 网页教材（可选） | 在目标浏览器检查布局、导航、链接、媒体和所选交互；明确离线及网络依赖 |
| PDF 教材（可选） | 渲染逐页检查分页、裁切、字体、代码及图文可读性；检查引用链接 |
| 概念视频（可选） | 实际播放成片，核对原理、动作顺序、字幕、配音同步、节奏及可读性；记录分辨率和时长 |
| Demo（可选） | 明确环境、依赖版本、启动步骤、输入、预期观察及教学结论；实际运行验证，说明网络/密钥/成本和非确定性；必要时提供标明录制时间的备用演示 |

工具不可用时记录未验证项，不能仅凭源文件或脚本宣称产物通过。未启用附件不阻塞课程；已启用附件未通过则标记待修复，或由用户明确接受延期/取消。

## 端到端试跑

本版本完成文档更新不等于完成真实课程试跑。选题仍由用户共同决定，不为测试而擅自确定正式课程。

首门真实小课完整执行：定位 → 框架 → 调研 → 样章 → 开发 → 试讲 → 修订 → 验收。记录各阶段耗时、用户评审次数、返工原因、等待点、状态续接问题、实际阅读时间及理解证据。以可执行性、评审负担和教学目标达成情况评估流程，不以文件数量评价成功。

先给出流程改进提案，由用户决定哪些升级为长期规则。未做真实学员验证的限制保留到验收与 README 状态中；一次试跑也不等于已证明普遍有效。
